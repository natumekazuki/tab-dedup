# v1.0.0

初回リリース。

- 操作した通常ウィンドウ内の重複タブを削除します。
- クエリを含める・無視する判定を選べます。クエリ要素の並び順は区別しません。
- 表示中のタブ、固定タブ、左端のタブの順に1タブを残します。
- ウィンドウごとに直近5回分の確定した削除履歴を保持し、URL・位置・固定状態を復元します。
- 未確定の操作は復元対象にせず、既存の確定履歴を維持します。履歴はウィンドウ閉鎖・Chrome再起動・拡張更新等で消えます。
- SVGから生成した拡張アイコンを同梱します。
- CIで単体テスト、構成・構文、配布ZIPを読み込んだ実拡張の削除・復元を確認します。

配布物は `tab-dedup-1.0.0.zip` です。展開したフォルダーをChromeのデベロッパーモードで読み込みます。GitHub配布物の自動更新はありません。

動作確認はNode.js 24とPlaywright付属Chromiumで行います。Chromeの最低対象版は102です。最低版実機、実ツールバーpopup、読み上げ等はCI確認の対象に含めません。
