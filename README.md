# Tab Dedup

操作したウィンドウ内だけの重複タブを整理する、Manifest V3のChrome拡張です。ビルドや外部ライブラリは不要です。

Chrome 102以降に対応します。

## 読み込みと使い方

1. Chromeで `chrome://extensions/` を開き、デベロッパーモードを有効にします。
2. 「パッケージ化されていない拡張機能を読み込む」で、このrepositoryの `extension/` を選びます。
3. 拡張アイコンをクリックし、「クエリを含めて削除」または「クエリを無視して削除」を選びます。表示件数は閉じる予定のタブ数です。

クエリを含める場合は `https://example.com/?id=1` と `https://example.com/?id=2` を区別し、無視する場合は同じURLとして扱います。どちらもフラグメント（`#` 以降）は区別します。同じURLでは表示中のタブ、固定タブ、左端のタブの順に優先し、1タブを残します。操作中にURL・ウィンドウ・固定状態が変わったタブや、新たに表示中になったタブは閉じません。

削除は即時実行です。入力中のフォームやページ内の状態は失われる場合があります。シークレットウィンドウは対象外です。`tabs` 権限はウィンドウ内のURLの比較に使用し、ページの内容を読んだり外部へ送信したりしません。

## 削除の復元

ウィンドウごとに直近5回分の削除を保存します。「直前の削除を戻す」で新しい履歴から1回ずつ、削除したタブのURL・元の位置・固定状態を復元します。既存のタブは閉じず、表示中のタブも切り替えません。現在のタブ配置やChromeの固定タブの制約により、元の位置へ戻せない場合があります。フォーム入力、ページ内の状態、閲覧履歴、タブグループは復元しません。

削除前にスナップショットを保存し、保存に失敗した場合は削除しません。削除が0件の操作は履歴を消費せず、復元に失敗したタブは再試行用に残します。

`storage` 権限を使い、URLを `chrome.storage.session` のメモリー内に保持します。外部送信や同期はしません。ウィンドウを閉じるとその履歴を消去し、Chrome再起動・拡張の無効化/再読み込み/更新でも履歴は消えます。

## 検証

Node.jsで `npm test` を実行します。実ブラウザー確認はユーザーの既存プロファイルと分離した非表示ブラウザーで行います。
